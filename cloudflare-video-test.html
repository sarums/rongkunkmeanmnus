How to test with the free R2 allowance

  1. Open Cloudflare Dashboard and create an R2 bucket.
  2. Upload a small MP4 test file (keep it under the free storage allowance).
  3. For this basic test, provide access to the file through a test URL. Do not put private credentials, API tokens, or secret keys in this page.
  4. Paste that URL above and press Load video. If it fails, check the URL, browser console, and whether the file can be fetched by the browser.
Security warning: A publicly accessible R2 video URL can be shared by anyone. This page is not a paywall and does not verify KHQR payments. For paid videos, keep the bucket private and use a backend/Cloudflare Worker to verify access and serve time-limited access. Never expose R2 secret keys in browser JavaScript.

Cloudflare R2 currently lists a free monthly allowance of 10 GB-month of Standard storage, 1 million Class A operations, and 10 million Class B operations. R2 is object storage, not an automatic video-transcoding/streaming service. Check current R2 pricing before use.
